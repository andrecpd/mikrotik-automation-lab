# Automação de Infraestrutura: 4 Filiais MikroTik

Repositório centralizado para o gerenciamento automatizado de roteadores MikroTik CHR utilizando Ansible, Python e a API do RouterOS[cite: 1].

## 📋 Pré-requisitos
- Servidor Ubuntu/Debian configurado na rede de gerência (`192.168.3.10/24`)[cite: 1].
- Acesso SSH/API habilitado nos roteadores das filiais.
